  - 직책

## (주)진흥관리 별도 수정
진흥관리 원본 표는 일반 양식과 구조가 다릅니다.

- 기간 행: 별도 전체 폭 셀로 다시 지정
- 보험료 행: 기간 아래 별도 셀로 다시 지정
- 기존에 보험료 9,000원이 기간 행에 들어가던 오류 수정
- 기간은 `입사일 2026년 8월 19일 로부터 ~ 퇴사일 까지` 형태로 기간 행 안에 표시
- 보험료는 그 아래 보험료 행 안에 표시

그 외:
- 대한종합개발 잘못된 `개시...` 문구 제거 상태 유지
- 위한씨엠 전용 좌표 유지
- `(인)` 안쪽 보정 유지
- 진한 전자서명 유지
- 대원에스테이트 수정 SVG 유지
- 사용자 수정 SVG 20개 그대로 유지

GitHub에는 `index.html`, `config.json`, `svgs/` 폴더 전체를 덮어쓰세요.
