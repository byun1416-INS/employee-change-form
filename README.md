# employee-change-form v15

v14 기준에서 요청사항만 수정한 버전입니다.

- 사용자가 직접 수정한 SVG 20개 그대로 유지
- 대원에스테이트 SVG를 새로 올린 `daewon(1).svg`로 교체
- 자동 입력 글자 크기 전체 확대
- 긴 단지명 등은 기존 자동축소(fit) 유지
- 모든 양식에서 전자서명 오른쪽에 `(인)`을 별도 HTML 텍스트로 고정 표시
- `(인)` 영역은 흰색 배경으로 다시 그려 기존 서명/문구와 겹치지 않게 처리
- 위한씨엠 별도 보정
  - 보험료 칸 좌표 지정
  - 신청인 이름 좌표 지정
  - 전자서명 좌표 지정
  - `(인)` 고정 표시
  - 기간 칸은 위한씨엠 전용 구조 유지
- 대한종합개발 전화번호/주소 입력 유지

GitHub에는 `index.html`, `config.json`, `svgs/` 폴더 전체를 업로드하세요.
