# employee-change-form v1.16

대한종합개발 최종 기간 수정

- 사용자가 Inkscape에서 직접 수정한 대한종합개발 SVG로 교체
- `개시(입사)일 :` 문구는 SVG 원본에 고정
- `종료일 : 퇴사일` 문구도 SVG 원본 유지
- 웹에서는 `개시(입사)일 :` 오른쪽 빈칸에 직원변경일만 9px로 자동 표시
- 기존처럼 코드가 `개시(입사)일`, `종료일`, `년/월/일` 문구를 다시 그리지 않음

그 외 기존 기능 유지:
- 서명 중심이 `(인)` 위에 겹침
- 더존환경/대한산업개발 4배, 나머지 2배 서명
- 헤더 오른쪽 `(주)인스송일헌`
- 진흥관리 제5조 제2항
- 접수완료 → PDF 생성 → Make 웹훅 전송
- 전체 자동입력 9px / 선 복구 레이어
