# employee-change-form v1.20

입사 / 퇴사 접수 화면을 완전히 분리했습니다.

## 입사
- 기존 입력항목 유지
- 취업규칙동의서 실시간 미리보기 표시
- 전자서명 필수
- PDF 다운로드 가능
- 접수완료 시 PDF 생성 후 Make 웹훅으로 PDF + 데이터 전송
- `has_pdf=true`

## 퇴사
- 단지명 / 성명 / 직원변경일(퇴사일)만 입력
- 실제 직책, 보험료직급, 생년월일 숨김
- 대한종합개발 전화번호/주소도 숨김
- 실시간 미리보기 전체 숨김
- 전자서명 전체 숨김
- PDF 다운로드 버튼 숨김
- PDF 생성 자체를 하지 않음
- 접수완료 시 Make 웹훅으로 데이터만 전송
- `has_pdf=false`

## 유지된 기존 기능
- v1.19 대한종합개발 최종 위치
- 서명 `(인)` 중심 겹침
- 전 위탁사 9px 자동입력
- 접수완료 하단 대표전화 안내
- Make 웹훅 구조 유지

다음 단계:
위탁사별 전용 링크/인증키는 Make 인증 웹훅과 연결해 별도 보안 분리합니다.
