# employee-change-form v1.10

v1.09 기준 수정사항

## 전자서명 확대
- 더존환경(주): 기존 대비 4배
- 대한산업개발: 기존 대비 4배
- 나머지 18개 위탁사: 기존 대비 2배
- `(인)` 쪽을 기준점으로 두고 왼쪽 방향으로 확대되도록 처리하여 `(인)` 침범을 줄임
- 기존 진한 검정 서명 설정 유지

## (주)진흥관리 기간
- 기존 양식 안의 `입사일(20  년  월  일) 로부터~ 퇴사일 까지` 등 고정 문구를 기간 셀 내부에서 모두 흰색으로 제거
- v1.09의 2줄 표시는 사용하지 않음
- 기간 칸에 `입사일 YYYY년 M월 D일 로부터 ~ 퇴사일 까지`를 9px 한 줄로 새로 작성
- 원본 선은 lineRepair 레이어로 복구

그 외 v1.09 설정 유지:
- 전체 자동입력 9px
- 20개 양식 원본 선 복구 레이어
- `(인)` 주변 선 보존
- 대한종합개발 개시일 날짜
- 위한씨엠 전용 좌표
- 긴 단지명 줄바꿈
