# employee-change-form v1.18

이번 버전은 실제 `index.html`과 대한종합개발 SVG를 다시 확인해서 수정했습니다.

- 접수완료 아래 실제 페이지 문구:
  **접수된 내용은 담당 직원이 확인 후 처리합니다. 문의사항은 대표전화 02-6481-0332로 연락해 주세요.**
- 대한종합개발:
  - 사용자가 직접 만든 `개시(입사)일 :` 문구 유지
  - 그 위에 남아 있던 옛 문구 `개시(입사)일로 부터 ~ 종료일 까지`만 제거
  - 날짜는 `개시(입사)일 :` 콜론 바로 오른쪽에만 자동 입력
  - 아래 `종료일 : 퇴사일`은 사용자 SVG 그대로 유지
- 기존 서명 위치/크기와 `(인)` 겹침 설정은 변경하지 않음
- 브라우저 캐시 방지 메타태그 추가

GitHub Pages 반영 시 ZIP 파일 자체가 아니라 압축을 푼 뒤
`index.html`, `config.json`, `upload-config.js`, `svgs/`, `lines/`를 저장소 루트에 덮어써야 합니다.
