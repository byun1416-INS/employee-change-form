# employee-change-form v1.19

대한종합개발 기간 위치 최종 보정

- 사용자가 SVG에 검은 박스로 표시한 위치를 그대로 좌표 기준으로 사용
- 검은 박스(`rect3`)는 최종 SVG에서 완전히 삭제
- 그 박스가 있던 자리 안쪽에 직원변경일만 9px로 출력
- 사용자가 직접 만든 `개시(입사)일 :` 및 `종료일 : 퇴사일` 문구는 그대로 유지
- 기존 위쪽 안내문구도 그대로 유지
- 이전 잘못된 날짜 위치는 더 이상 사용하지 않음

기존 기능 유지:
- 서명 중심이 `(인)`과 겹치도록 배치
- 더존환경/대한산업개발 4배, 나머지 2배 서명
- 헤더 오른쪽 `(주)인스송일헌`
- 접수완료 아래 담당 직원 확인/대표전화 안내
- 접수완료 → PDF 생성 → Make 웹훅 전송
- 진흥관리 제5조 제2항
- 자동입력 9px / 원본 선 복구
