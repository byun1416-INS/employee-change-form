# employee-change-form v14

사용자가 Inkscape에서 직접 수정한 SVG 20개를 최종 원본으로 사용합니다.

- 사용자 수정 SVG를 그대로 `svgs/`에 포함
- 원본 고정 문구/표선은 건드리지 않음
- 비워둔 값 영역에만 자동 데이터 삽입
- 기간 칸은 사용자가 비워둔 전체 셀 안에 HTML로 새로 배치
- 보험료 칸도 빈 셀 중앙에 자동 삽입
- 대한종합개발은 전화번호/주소 입력란 표시
- 서명은 각 양식의 `(인)` 바로 왼쪽 영역까지만 사용하고 `object-fit: contain`으로 자동 축소
- 성명, 서명일, 전자서명을 각각 별도 좌표로 처리
- 화면 버전 v14

GitHub에는 `index.html`, `config.json`, `svgs/` 폴더를 전부 업로드하세요.
