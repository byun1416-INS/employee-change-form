# employee-change-form v11

이 버전은 이전처럼 양식을 비슷하게 다시 그린 것이 아닙니다.

- 사용자가 다시 업로드한 원본 PDF 20개를 각각 `pdftocairo`로 SVG 벡터 DOM으로 변환
- 표, 제목, 본문, 글꼴 윤곽, 줄 위치, 회사별 특수 양식은 원본 벡터 그대로 표시
- HTML 위에서 단지명/직책/성명/생년월일/변경일/보험료/서명만 실시간 오버레이
- 원본의 `20 년 월 일`, `월 원` 같은 입력용 빈 문구는 정확한 PDF 좌표에 흰색 마스크 후 새 값을 표시
- 대한종합개발의 전화번호/주소/특수 표, 위한씨엠/진흥관리 등 별도 원본 모양을 그대로 유지
- 신한영관리 원본 파일 사용
- PDF 파일 자체를 브라우저 배경으로 사용하지 않고 SVG로 변환한 HTML/벡터 화면

GitHub 업로드: `index.html`, `config.json`, `svgs/` 폴더를 모두 올리세요.
