# employee-change-form v12

v11 원본 SVG 방식은 그대로 유지하고, 사용자가 20개 실제 화면을 검수한 결과를 반영한 보정 버전입니다.

- 전체 입력 글자 크기 확대
- 태룡에스디 / 한영파트너스에프에이치 / 현대하우징 / (주)진흥관리: 글자 크기 위주 확대
- 나머지 일반 양식: 입사일 날짜 마스크가 왼쪽 표선을 침범하지 않도록 period cell 내부로 자동 재계산
- 위한씨엠: 기간 칸과 보험료 칸을 원본 표 경계 기준으로 완전히 재배치
  - '재직기간 전체' 문구는 원본 유지
  - 입사일 / '~ 퇴사일'은 기간 칸 안에서 2줄 배치
  - 보험료는 보험료 칸 안에 '월 9,000원' 형태로 배치
- 대한종합개발: 전화번호 / 주소 입력란 유지 및 필수 표시
- 원본 PDF 20개 → SVG 벡터 원본 형태 유지
- 화면 버전 v12
