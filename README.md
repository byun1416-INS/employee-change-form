# employee-change-form v9

v8의 HTML 실시간 취업규칙동의서 방식을 유지하면서 원본 양식에 더 가깝게 다듬은 버전입니다.

- 표 칸 높이와 내부 여백 확대
- 본문/표/서명부 글자 크기와 줄간격 조정
- 긴 단지명 자동 줄바꿈 유지
- 임의 단지명/직책 입력 예시 제거
- 20개 위탁사별 문구와 전용 레이아웃 유지
- `신한영관리` 명칭 유지
- 우측 하단 및 미리보기 상태에 v9 표시
- PDF 배경 이미지 없이 HTML 자체를 PDF로 저장

GitHub 저장소의 기존 `index.html`을 이 버전으로 교체하면 됩니다.
